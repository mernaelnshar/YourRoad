# YourRoad Educational Platform

## About The Project
YourRoad is an educational platform that helps students find teachers and book lessons easily.

The platform allows students to register, log in, and view teachers and students data through organized dashboards.

---

## Features
- Student Registration
- Login System
- Teachers Data Table
- Students Data Table
- Simple Dashboard Interface
- Responsive Design using Bootstrap

---

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
